# Numero-magique

Ce projet m'a été proposé pendant ma première année au sein de Coda, sur le module de la programmation bas niveau.
Ce projet reprend le principe du juste prix, l'ordinateur choisira au hasard un numéro entre 1 et 100 (bornes incluses) et l'utilisateur devra le trouver.

Voici les conditions qui m'ont été imposées : 

- Être en langage C.
- Le code ne doit contenir qu'un seul fichier : main.c et une seule fonction : la fonction main.
- Le code doit contenir au minimum une boucle et trois conditions et utiliser scanf et printf.

Bonus que j'ai rajouté : 

- Vérifier si l'utilisateur rentre bien un numéro entre 1 et 100 (et redemande une saisie si besoin).
- Rajouter un nombre limité de 10 tentatives.
